# TODO / 향후 개선 로드맵

"먼저 동작하게, 그다음 정확하게(make it work, then make it right)" 원칙에 따라,
MVP에서는 단순화하고 정밀화는 아래로 미룬 항목들.
각 항목은 "왜 지금 안 하고 미뤘는지"까지 적어 우선순위 판단을 드러낸다.

## 데이터 생성(시뮬레이터) 정밀화

- [ ] **60대 소득을 이봉분포(bimodal)로 개선**
      현재: 단봉 로그정규로 단순화.
      개선: '연금+소액소득' 구간과 '자산가/임원' 구간을 혼합분포로 생성.
      미룬 이유: MVP는 전체 파이프라인 통과가 목표. 소득 분포 정밀도는
                모델이 도는 걸 확인한 뒤 올려도 늦지 않음.

- [ ] **가구 단위 소득 반영 검토**
      현재: 개인 임금근로자 기준 소득.
      개선: 가구 수신 잔액·주담대 상환능력을 볼 경우 맞벌이 등 가구총소득 반영.
      미룬 이유: 현재 모델 범위는 개인 대출 채권. 가구 단위는 스코프 확장 시.

- [ ] **소득 표준편차를 실제 분위수 통계로 교체**
      현재: 평균의 30~40%로 가정.
      개선: KOSIS 분위수(하위25%/상위25%) 데이터로 std를 역산.

- [ ] **외부 충격에 거시경제 시나리오 연결**
      금리 인상, 경기 침체 등을 시계열로 주입 → 드리프트 감지 실험에 활용.

## 모델 / MLOps (2·3단계)

- [ ] 데이터를 CSV → DB(Postgres) 적재
- [ ] 일별 배치 자동화 (Airflow 또는 Prefect)
- [ ] 모델 버전 관리 + 성능 모니터링
- [ ] 데이터 드리프트 감지 → 자동 재학습 트리거
      (시뮬레이터에서 거시 환경을 바꿔 분포 변화를 유발해 실증)
- [ ] 시계열 모델(LSTM 등) 및 SHAP 설명가능성 추가
