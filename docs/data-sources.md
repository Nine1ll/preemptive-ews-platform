# 데이터 출처 및 파라미터 근거

시뮬레이터의 인구·소득 파라미터가 어디에 근거하는지 기록한다.
"왜 이 숫자인가?"라는 질문에 답하기 위한 문서.

### 표준편차(std) 설정 근거
통계 보도자료에는 연령대별 표준편차가 직접 제시되지 않는다.
→ **평균의 약 30~40%를 std로 설정**(가정값). 소득 분포의 현실적 변동성을
   반영하기 위한 근사이며, 로그정규분포로 생성해 음수·비대칭을 보정한다.
   (이 부분은 '가정'임을 명확히 문서화 — 면접에서 정직하게 밝힐 것)

### 소득 분포 형태: 로그정규분포(log-normal)
실제 소득은 정규분포가 아니라 오른쪽 꼬리가 긴 로그정규분포를 따른다.
`np.random.normal`을 쓰면 (1) 저소득 구간에서 음수 발생, (2) 고소득 극단값
미표현 문제가 생긴다. 따라서 `rng.lognormal(mu, sigma)`로 생성한다.

평균(mean)·표준편차(std)를 로그정규 파라미터로 변환:
```
mu    = ln(mean^2 / sqrt(std^2 + mean^2))
sigma = sqrt(ln(1 + std^2 / mean^2))
```

## ⚠️ 60대 소득의 특수성 (향후 개선 대상)

60대는 단일 로그정규분포로 표현하기 어렵다. 정년 이후 재취업·촉탁직·시간제
전환이 몰려 평균 낙폭이 크고, 실제로는 '연금+소액소득' 구간과 '자산가/임원'
구간으로 나뉘는 **양극화(이봉분포, bimodal)** 구조다.

→ MVP 단계에서는 단봉 로그정규로 단순화. 정밀화는 TODO 로드맵 참조.

## 소득별 소비성향

2024년 4분기 평균소비성향은 69.0%이나, 소득 분위별 편차가 크다. 하위 20%(1분위)는 133.6%로 소득보다 많이 지출(적자)하는 반면, 상위 20%(5분위)는 55.0%에 그친다. 본 시뮬레이터의 소비성향 범위(0.85~1.10)는 이 분포를 단순화해 반영한 것이다.
